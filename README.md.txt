# Sales Report – Анализ продаж из CSV

Скрипт на Python для автоматической обработки данных о продажах.  
Читает CSV-файл с исходными данными, вычисляет выручку по каждой категории товаров и сохраняет сводный отчёт в Excel-файл.

## 🔧 Стек
- Python 3
- pandas
- openpyxl

## 📁 Структура проекта
- `main.py` – основной скрипт
- `data.csv` – файл с исходными данными (пример)
- `sales_summary.xlsx` – результат работы скрипта (создаётся автоматически)
- `requirements.txt` – список зависимостей
